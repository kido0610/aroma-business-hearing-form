# 業務確認シート（ヒアリングフォーム）

アロマ業務管理アプリの仕様確認に使う、単体HTMLのヒアリングフォームです。

## 仕様

- `index.html` の1ファイルのみで動作します
- 外部ライブラリ・外部CSS・外部フォントを読み込みません
- 回答を外部サーバーへ送信しません（`fetch` / `XMLHttpRequest` / Cookie を使用していません）
- 入力内容はブラウザの localStorage にのみ保存され、端末外へは出ません
- 回答は最後に「回答をコピーする」でテキスト化し、利用者自身が貼り付けて送る方式です

## 注意

このページは URL を知っていれば誰でも開けます。
機密情報や実在する顧客の氏名・連絡先を入力する用途では使用しないでください。
フォーム内にもその旨を表示しています。
